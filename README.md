## Projects

- **[AeroLand](https://github.com/tejaDhulipala/Aviation-Emergencies-Benchmark)**: a benchmark of 50 engine-out emergency scenarios testing whether multimodal LLMs can pick the safest landing site from satellite imagery. The main bottleneck turned out to be terrain identification, not aviation knowledge. [Technical report](https://bit.ly/46T3Sef)
- **[Better Every Day](https://github.com/tejaDhulipala/BetterEveryDay)**: a time-tracking and journaling app built with React Native and TypeScript.
- **[Progress Tracker](https://github.com/tejaDhulipala/ProgressTracker)**: a React Native (Expo) gym tracker that logs workouts to Google Sheets.
- **Maritime search & rescue RL environment**: extended an open-source drone swarm search environment with real ocean current data and Bayesian drift modeling.
- **ML from scratch**: a dense neural network with hand-written backpropagation (95.5% on MNIST), plus CartPole solved with the Cross-Entropy Method, Deep Q-learning, and REINFORCE.
